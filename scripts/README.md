# env-vault Scripts

This directory contains various utility scripts for `env-vault` development, testing, and deployment.

## Available Scripts

- `setup-bitwarden-cli.sh`: Installs and configures the Bitwarden CLI (`bws`).
- `setup-gcloud-cli.sh`: Installs and configures the Google Cloud CLI (`gcloud`).
- `run-tests.sh`: Executes all unit and integration tests for the project.
- `build-release.sh`: Builds `env-vault` binaries for multiple platforms and architectures.
